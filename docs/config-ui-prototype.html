沙箱授权

配置沙箱内的目录操作权限及命令执行权限，保存后立即生效。

安全警示：授权目录会被沙箱内的 AI 代理无审批写入（工作区之外），请勿配置存储重要文件的目录。
工作区外的受信可写目录

支持通配符：D:\Shared\**（子树）、D:\Data\*（一级子目录）、 D:\Work\202?（单字符）。

校验规则：Windows 路径或通配符；非法条目会在保存前标红提示，不会静默丢弃。

示例提示：目录 D:\Work\2026 不存在。

未命中任何规则时的默认动作

delegate 表示维持 dsh 现有行为（按需询问）；allow / ask / deny 会覆盖未命中命令的处理。

放行规则（按顺序匹配，最后一条命中生效）

pattern 支持 *（任意多个字符）与 ?（单个字符）； git * 忽略 git 后任意参数。allow=免询问（仍受文件沙箱约束）、 ask=弹审批、deny=拦截。

空 pattern 的行不会保存；工具留空任意时规则对所有 shell 工具生效。

示例提示：pattern 「rm -rf *」与 deny 组合不会被写入。

提示：撤销授权后，已物化到目录 DACL 的 ACE 不会被自动移除（Windows）；如需清理请用 scripts/revoke.mjs。注意不要在本分节内使用 pnpm install 全局重装 web profile（github git+ssh 依赖会失败）。
